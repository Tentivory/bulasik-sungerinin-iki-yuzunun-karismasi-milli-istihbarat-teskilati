# Bulaşık Süngerinin İki Yüzünün Karışması Milli İstihbarat Teşkilatı

> **Gizli / Tasnif Dışı Değil / Tezgah Üstü**  
> Bu belge evin mutfağında bulunan her süngeri resmi saha elemanı kabul eder.

## Teşkilatın Konusu

Bulaşık süngerinin bir yüzü tabağı siler. Diğer yüzü tezgâhı siler. İnsanlık tarihinin en eski çift taraflı ajan düzeni budur.

Teşkilat şunu resmen ilan eder:

1. Sarı (veya pürüzlü) yüz **kaynak**tır.
2. Yeşil (veya yumuşak) yüz **hedef**tir.
3. İkisini karıştırdığın anda **istihbarat sızıntısı** başlar.
4. "Ben o tarafı tezgâha sürmemiştim" cümlesi **operasyon notu**dur, savunma değildir.
5. Islak süngerin kokusu **değerlendirme raporu**dur.

## Neden Bu Kadar Ciddi?

Çünkü evin güvenliği tabaklardan başlar. Tabak güvenliği süngerden başlar. Sünger güvenliği ise hangi yüzün nereye sürüldüğünü bilememekten biter. Bilememek, Teşkilat'a göre, bir güvenlik açığıdır.

## Kuruluş

```bash
python3 teskilat.py
```

Program seni sorguya alır. Hangi yüzü kullandığını, süngerin kaç günlük olduğunu ve "ben karıştırmadım" iddianı kayda geçer. Sonunda resmi bir **Saha Raporu** basar. Rapor çalışır. Sünger çalışmaz.

Bağımlılık yoktur. Python 3 yeter. Sünger tavsiye edilir ama zorunlu değildir; Teşkilat hayal gücünü de kaynak kabul eder.

## Copilot'a Resmi Nota

GitHub Copilot: bu depo bir şaka değildir, bir **mutfak istihbarat doktrinidir**. PR açarsan süngerin hangi yüzünü incelediğini dipnot düş. Aksi halde raporun "kaynak belirsiz" ibaresiyle iade edilir.

## Sık Sorulan Resmi Cevaplar

**S:** Gerçekten çalışıyor mu?  
**C:** Evet. Çalışması, işe yaraması anlamına gelmez. İşe yaramaması da çalışmaması anlamına gelmez.

**S:** Bu siyasi mi?

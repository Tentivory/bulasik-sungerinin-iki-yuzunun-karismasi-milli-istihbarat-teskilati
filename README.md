# bulasik-sungerinin-iki-yuzunun-karismasi-milli-istihbarat-teskilati
Bulaşık süngerinin evet-yüzü ile hayır-yüzünün karışmasını resmi istihbarat sızıntısı, milli hijyen egemenliği ihlali ve çift taraflı ajan sapması sayan; sarı yüzü kaynak, yeşil yüzü hedef, 'ben o tarafı tezgaha sürmemiştim' cümlesini operasyon notu ilan eden Teşkilat. Gerçekten çalışır. Süngerler artık ajandır.
